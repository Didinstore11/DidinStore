Tambah produk dan foto dari HP. Foto akan dikompres agar ukuran file lebih ringan.

Penting: Ini situs statis Netlify. Halaman ini tidak bisa menyimpan perubahan langsung ke server. Setelah selesai, unduh file products.js, ganti file yang lama di folder proyek, lalu deploy ulang folder proyek ke Netlify. Perubahan tidak otomatis terlihat oleh pelanggan sebelum deploy ulang.

Cara menerapkan perubahan

  1. Tekan Unduh products.js.
  2. Di folder proyek DIDIN STORE, ganti file products.js lama dengan file yang baru diunduh.
  3. Pastikan folder yang diunggah berisi index.html, app.js, config.js, products.js, style.css, dan netlify.toml.
  4. Upload/deploy ulang folder proyek di Netlify Drop. Setelah deployment selesai, buka website dan tes foto serta keranjang.
